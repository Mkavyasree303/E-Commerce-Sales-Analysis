# SQL Query Collections

This folder contains the SQL work developed as part of the **E-Commerce Sales Analysis** project using MySQL.

The queries are organized into two sections: **Main Business Analysis** for portfolio-focused SQL work and **Complete Practice Work** for the full collection of 200+ SQL questions and solutions completed during the project.

---

## 📊 Main Business Analysis

**File:** `main_business_analysis.sql`

This file contains the selected SQL queries that best demonstrate practical data-analysis and business problem-solving skills.

The analysis covers areas such as:

* Customer analysis
* Product and category performance
* Sales and revenue analysis
* City-wise analysis
* Payment analysis
* Customer spending behavior
* Business-oriented SQL questions
* Advanced SQL concepts
* Subqueries, views, and other analytical techniques

These queries are highlighted as the **main portfolio work** because they focus on extracting meaningful information from the e-commerce dataset.

---

## 📚 Complete SQL Practice Work

**File:** `../practice/sql_practice_200_plus_questions.sql`

This file preserves the **complete 200+ SQL question-and-query practice work** completed while building the project.

It includes practice across multiple SQL concepts, from fundamental queries to more advanced topics such as:

* SELECT and filtering
* Sorting and limiting results
* Aggregate functions
* GROUP BY and HAVING
* CASE statements
* Joins
* UNION and UNION ALL
* Views
* Indexes
* Single-row subqueries
* Multiple-row subqueries
* `IN` and `EXISTS`
* Business-oriented SQL problems

This collection demonstrates the learning and problem-solving process behind the final project.

---

## 🗂️ Why the Queries Are Separated

The queries are intentionally divided into two collections:

**Main Business Analysis**
→ Focused on the strongest queries for portfolio and recruiter review.

**Complete Practice Work**
→ Preserves the full learning journey and 200+ questions without making the main analysis file unnecessarily large.

This structure makes the repository easier to navigate while still keeping the complete SQL work available for reference.

## 🎯 Project Objective

The objective of this SQL project is to analyze an e-commerce database and use SQL to answer practical business questions related to customers, products, orders, revenue, payments, and sales performance.

The project focuses not only on writing SQL queries, but also on using query results to support **business-oriented analysis and decision-making**.
